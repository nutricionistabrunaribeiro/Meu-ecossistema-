# Versão 48 — Widgets independentes e lista de agenda

Pacote completo baseado na versão 47, preservando as funcionalidades anteriores.

- Códigos individuais para cada widget; o tipo não depende mais da última escolha feita no Scriptable.
- Script genérico sem seleção silenciosa de hidratação quando o Parâmetro estiver vazio.
- Agenda com todos os compromissos salvos da conta, incluindo concluídos, histórico e futuros, nomes de clientes e páginas para os itens que não couberem no widget.
- A conexão já existente continua funcionando. Não precisa gerar outra chave se ela já autoriza os indicadores usados.

Consulte WIDGETS-IPHONE-LEIA-ME.md. Atualize o GitHub e também o código no Scriptable. A função do servidor já foi atualizada no projeto atual, mantendo compatibilidade com a versão 47.
