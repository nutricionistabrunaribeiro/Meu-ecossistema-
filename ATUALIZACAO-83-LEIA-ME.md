# Meu Ecossistema • Bruna Ribeiro — versão 83

## Treinamentos vencidos: abertura direta no card

O card **Treinamentos vencidos** agora abre uma lista no próprio painel de **Supervisão**.

### Como usar

1. Acesse **Trabalho → Supervisão**.
2. Selecione **Saber Nutrir**, **Bruna Ribeiro** ou **Todos**.
3. Toque em qualquer parte do card **Treinamentos vencidos**.
4. Abaixo do card, aparecerão os clientes, os temas, as datas de realização e as datas em que a validade terminou.
5. Toque em **Fechar** ou no próprio card para recolher a lista.

A abertura utiliza um controle nativo do navegador, sem depender de uma função JavaScript ao tocar. A lista utiliza exatamente os mesmos dados e filtros da contagem do card. A reciclagem mais recente do mesmo tema substitui a validade antiga.

## Como conferir se a nova versão carregou no iPhone

Na parte superior do painel **Minhas entregas** aparece a indicação discreta **v83**.

Se não aparecer **v83**, o dispositivo ainda está exibindo uma versão anterior. Aguarde a publicação no Vercel e atualize o site no Safari. Se estiver utilizando o ícone na Tela de Início, feche e reabra o aplicativo; se a versão antiga persistir, atualize pelo Safari e confira novamente.

## Atualização

Substitua no GitHub o `index.html` anterior pelo `index.html` desta pasta.

Nenhum dado é apagado e nenhuma atualização de banco de dados é necessária.
