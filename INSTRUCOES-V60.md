# Meu Ecossistema — V60

## Publicação

1. Extraia o pacote.
2. Substitua os arquivos do repositório do GitHub pelo conteúdo da pasta.
3. Confirme o commit no GitHub.
4. Aguarde o deploy automático da Vercel.
5. No iPhone, feche e abra novamente o aplicativo instalado para receber o cache V60.

## Conferência rápida

- Financeiro Pessoal: criar uma conta parcelada de teste e conferir as parcelas futuras.
- Financeiro do Trabalho: criar uma entrada recorrente e navegar pelos meses.
- Agenda: criar um compromisso semanal com data final e conferir as ocorrências.
- Marcar somente uma ocorrência como concluída.
- Editar ou excluir uma ocorrência e escolher entre somente ela ou ela e as próximas.
