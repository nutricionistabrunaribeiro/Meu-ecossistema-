# Meu Ecossistema • Versão 62

Base: atualização 61. Inclui o devocional completo de dezembro, o PDF e 31 artes para stories em 1080 × 1920 pixels.

## Publicação
Extraia o ZIP e substitua SOMENTE index.html na raiz do seu repositório no GitHub. Mantenha os demais arquivos. Aguarde a publicação automática na Vercel e reabra/atualize o aplicativo. Não é preciso publicar a versão 61 antes: este index já contém aquela atualização.

## Como usar
Na Presença → Devocional de dezembro → escolha o dia → Arte para stories.
Use Baixar arte ou Compartilhar imagem. No iPhone, quando disponível, escolha Salvar Imagem no compartilhamento. Depois abra o Instagram e selecione a imagem na galeria para seu story.
Se o navegador não oferecer compartilhamento de arquivos, use Baixar arte.

As frases são reflexões autorais inspiradas nas passagens, não transcrições bíblicas. Cada arte informa sua referência. A paleta das artes é fixa (marsala, champagne e rosa seco), independentemente do tema da interface.

O PDF completo para impressão continua no aplicativo. Não foram adicionadas alterações de banco de dados nem registro de progresso.
